# Tank Pumping Control — OpenPLC (IEC 61131-3)

A PLC program in Structured Text that controls the pumps of a multi-compartment water tank with manual/auto modes, level setpoints and timers.

## Tech stack
- OpenPLC Editor · Structured Text

## Features
- Manual/automatic mode and emergency stop
- Level-based start/stop with analog level input
- On/off delay timers and thermal protection
- Pin mapping for OpenPLC runtime

## Getting started
Open `project.json` with OpenPLC Editor, compile, and upload to an OpenPLC runtime.
